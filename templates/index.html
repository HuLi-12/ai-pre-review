What Makes Review Cockpit Different
Changed-Line Review
Traditional AI review scans old code and flags pre-existing issues as if they were new. We only analyze added and modified lines in the patch — no legacy noise, no false attribution.
只审本次改动，不翻旧账
Risk-Aware Routing
Not all files are equal. We score each file by path pattern, change size, and keyword to decide analysis depth — skip, normal, or deep review.
高风险深析，低风险跳过
Hybrid Rule + AI Engine
15 static rules catch deterministic issues (passwords, unsafe SQL). AI catches what rules cannot understand (missing null check, transaction risk). Both agree → confidence bonus.
规则抓确定性问题，AI 理解上下文
Confidence Gate
Every finding has a confidence score. Low confidence (< 0.60) is hidden by default. High confidence (≥ 0.80) is GitHub comment-ready. You decide what to trust.
低置信度隐藏，高置信度可回写
GitHub-Native Comment
High-confidence findings can be auto-posted to the PR conversation. Re-running updates the existing comment — no spam. Line-level review comments supported for precise feedback.
幂等更新，不重复评论
Signature Dedup
Merges duplicate findings by file + type + line bucket + title similarity. Same issue caught by both static rule and AI? Automatically merged with an agreement bonus to confidence.
签名去重，避免重复建议
